# AtomRL Getting Started

First identify the owner of the change:

- AtomRL orchestration and native trainers: `ATOM/atomrl/atomrl/`
- AtomRL inference backends: `ATOM/atomrl/atomrl/engine/inference/`
- AtomRL VERL plugin: `ATOM/atomrl/atomrl/plugin/verl/`
- Lumen quantized training engine: `ATOM/atomrl/atomrl/lumen/`

For AtomRL work, start with `ATOM/atomrl/README.md`. For Lumen work, start with `ATOM/atomrl/lumen/README.md`. The removed Lumen TRL/VERL adapters are not supported public APIs.
