Key Features

AITER-optimized training kernels and model-level integrations for quantized pretraining, fine-tuning, and post-training

⚡

Unified Model Optimization

LumenConfig.enable(model) coordinates quantization, AITER kernel patches, model patches, and distributed optimizations without changing the public training loop.

⚙

Unified QuantConfig

A single configuration object governs format (E4M3, E5M2, MXFP8, Hybrid), scaling strategy (Dynamic, Delayed, Blockwise), and all precision knobs.

▲

Up to 2x Peak FLOPS

FP8 on MI300X achieves ~2,615 TFLOPS vs ~1,307 TFLOPS for BF16. End-to-end training speedup of 1.4-1.7x depending on workload.

♺

AITER Kernels

AITER-optimized training kernels with an ASM -> CK -> Triton fallback chain. Covers attention, GEMM, normalization, RoPE, MoE, MLP, cross-entropy, and quantization.

☷

MORI Communication

Native RDMA + GPU communication with FP8 all-gather (~2x bandwidth saving) and compute-communication overlap (AG/fwd, RS/bwd).

⚗

Backend-Agnostic

Same quantization semantics across FSDP, FSDP2, and Megatron-LM backends. Supports SFT, pre-training, and RL workloads (GRPO, PPO, DAPO) with SGLang or vLLM rollout.

Architecture

Lumen integrates AITER-optimized kernels at the model level and owns the quantized training lifecycle

Quick Start

Enable the AITER-powered model training optimization stack with one configuration

Install
# User install
git clone https://github.com/ROCm/ATOM.git
cd ATOM
git checkout main
pip install torch triton amd-aiter
LUMEN_BUILD_EXTENSIONS=1 pip install --no-build-isolation --no-deps -e .

# Developer install
pip install torch triton amd-aiter pytest pytest-xdist torchao
LUMEN_BUILD_EXTENSIONS=1 pip install --no-build-isolation --no-deps -e .
Unified Training Optimization
from atomrl.lumen import LumenConfig

lumencfg = LumenConfig(
    format="fp8_e4m3",
    scaling="delayed",
    fp8_attn="dpa",
    lumen_norm=True,
    lumen_linear=True,
    fused_mlp=True,
    fp8_param_gather=False, # enable with a distributed DP group
)
lumencfg.enable(model)

# Training loop unchanged
output = model(input_ids)
loss.backward()
optimizer.step()
