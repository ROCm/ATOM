Q4: No speedup is claimed — this is a crash-avoidance stopgap, and the PR says so. The mechanism on the affected arch is substituting pure-torch ops (shift/and/masked_fill_) for the fused sgl_kernel CUDA kernel, paying extra transient memory (~B x V int32+bool temporaries, reviewer measured ~485 MiB at B=256, V=248320) and a few extra kernel launches, but only on devices whose arch is missing from the image; gfx950 pays nothing because the gate keeps the native kernel there. Reviewer's op-level numbers (5->48.6 us at B=1) were accepted as stopgap cost with end-to-end impact measured negligible.
