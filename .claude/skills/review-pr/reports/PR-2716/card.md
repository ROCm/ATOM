## ATOM PR #2716 — perf(tokenizer): reuse cached prefix hashes across requests

**Keeps the prompt's chained per-block hashes inside the tokenizer cache's stored prefix record and, on a later turn that matches that prefix, copies the matched complete blocks' links and hashes only the new tail — instead of the frontend rehashing the whole prompt on every request.**
